# RetKit MCP — студия как инструмент чужой модели

Пользователь приносит свою модель (свой Claude, свою подписку), студия отдаёт ей
инструменты. **Владелец студии не платит за генерацию ничего** — ни за токены,
ни за ключи. Ключей моделей внутри этого сервера нет и быть не должно.

## Что получает модель

| Инструмент | Что делает |
|---|---|
| `retkit_list_blocks` | каталог блоков: фильтры по набору (system/promo), уровню, категории, поиск |
| `retkit_get_block` | все слоты блока: тип, значение по умолчанию, допустимые варианты |
| `retkit_compose_preview` | собирает письмо и возвращает размер и предупреждения; ничего не пишет |
| `retkit_save_mail` | сохраняет письмо в `email-base` |
| `retkit_list_mails` | что уже есть в базе |

Ответы намеренно компактные. Собранное письмо весит десятки килобайт, поэтому
HTML отдаётся только при `include_html: true` — иначе окно контекста выгорает за
несколько шагов.

## Подключение (Claude Desktop / Claude Code)

Студия должна быть запущена: `npm start` в папке проекта.

```json
{
  "mcpServers": {
    "retkit": {
      "command": "node",
      "args": ["/полный/путь/к/retantion-future/mcp/retkit-mcp-server.mjs"],
      "env": {
        "STUDIO_URL": "http://127.0.0.1:3000"
      }
    }
  }
}
```

Если студия на Heroku и закрыта Basic Auth — добавьте в `env`:

```json
"STUDIO_URL": "https://ваш-домен",
"STUDIO_USER": "логин",
"STUDIO_PASSWORD": "пароль"
```

Пароль лежит в конфиге MCP-клиента на машине пользователя и в репозиторий не
попадает.

## Как этим пользуются

Человек пишет своей модели обычными словами:

> Собери системное письмо про подтверждение почты: логотип, заголовок,
> приветствие, два абзаца и кнопка. Сохрани как `confirm-email`.

Модель сама вызывает `retkit_list_blocks` (набор `system`), уточняет слоты через
`retkit_get_block`, собирает дерево, проверяет через `retkit_compose_preview` и
сохраняет. Ни одного запроса к платным API студии.

## Проверка

```bash
node scripts/test-mcp-server.mjs
```

Поднимает студию в демо-режиме, подключается настоящим MCP-клиентом и проверяет
весь путь: каталог → слоты → сборка письма → внятные ошибки.
