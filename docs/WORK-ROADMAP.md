> **Дорога к версии 1.0 — в отдельном документе: `docs/ROADMAP-1.0.md`.**

> текст), главная находка — в студии живут ДВА агента без единого общего

а не в конце. Даты не ставим — ставим порядок и ворота приёмки.

Решение по развёртыванию (14.09.2026): **локально-первым**. Студия крутится на
машине человека, его Клод по MCP ходит на `127.0.0.1`. Общая — только база
писем через git. Heroku — демо-витрина в режиме «только чтение».

## Этап 9 — Разбор `server.js` 🔶 в работе

Все ручки студии разбирала одна лестница `if`-ов длиной в девятнадцать тысяч
строк. Это упиралось в работу на каждом этапе: чтобы понять ручку, её надо
найти среди сотни соседей; чтобы добавить новую — вклиниться в середину;
любая правка рядом задевает всё. Переписать разом нельзя: в лестнице живут
ручки, которых никто не трогал год, и их поведение нигде, кроме кода, не
описано.

Поэтому маршрутизатор поставлен рядом, а домены переезжают по одному.

- [x] `src/router.js` — точный путь и префикс, хвост и `?query` разобраны за
      обработчика. Главное свойство: чужой запрос пропускается дальше
      (`dispatch` → `false`), иначе переезд по одному домену невозможен
- [x] первым переехал домен «кто работает и в чьём черновике»:
      `src/routes/workspace-routes.js`, 6 ручек (`/api/me`, `/api/me/name`,
      `/api/drafts*`, `/api/mail-lease*`). Выбран не случайно — это самые
      молодые ручки студии, их поведение целиком описано тестами, и переезд
      можно сверить
- [x] зависимости передаются снаружи одним объектом: модуль не тянет за собой
      половину `server.js` и проверяется подставными функциями
- [x] `scripts/test-router.mjs` — 21 проверка и **храповик на лестницу**:
      98 ручек, может только уменьшаться. Новая ручка в лестницу не
      добавляется — только в маршрутизатор
- [x] сверено вживую по HTTP: все шесть ручек отвечают через маршрутизатор
- [x] вторым уехало **подключение своего агента**: `src/routes/mcp-routes.js`,
      3 ручки (`/api/mcp/setup`, `/api/mcp/install`, `/api/mcp/install-skill`).

- [x] отдельная проверка: в ручках подключения нет и не появится ключей
