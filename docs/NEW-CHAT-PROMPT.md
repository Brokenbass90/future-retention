# Старт нового чата по RetKit / Future Retention Studio

Скопируй это в начало нового чата.

## Контекст
RetKit — локальная email-студия (Node, Pug+Stylus → `build-mail.js`, инлайн CSS).
Источник истины = код блока. Три глубины правки: верстальщик (workbench),
«немного шарит» (карандаш/DnD-конструктор), новичок (AI собирает из блоков).
Рабочая папка: `retantion-future`. Деплой на Heroku делает пользователь сам
(агент НИЧЕГО не пушит). Из песочницы агента сеть до OpenAI закрыта — AI-части
проверяются только в приложении с ключом; offline-логику покрывает `npm test`.

## Важные правила
- Pug+Stylus toolchain — трогать осторожно (мирорить server/client RTL: `src/rtl.js` ↔ `public/workbench.js applyRtl`).
- Любая правка фронта проверяется визуально пользователем после пуша (агент не видит рендер).
- Бэкапы правок: файлы `*.bak-ai*`.
